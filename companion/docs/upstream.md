# Independent companion package

This package uses standard NetworkX graphs and is distributed independently
from this repository. Its APIs do not require inclusion in NetworkX.

The package includes both local quadrangle coefficients and averages, plus
combined pairs, global ratios and cycle counts. Its documentation explicitly
states the unweighted i-quad transformation from square clustering and labels
the derived weighted global extension.

Run the development commands in the companion README from `companion/`.
CI checks tests, lint, formatting and distributions on Python 3.12, 3.13 and 3.14.
